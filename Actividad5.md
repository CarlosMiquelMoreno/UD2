| Malware | Explicación |
| ------- | ----------- |
| Adware | Anuncios no deseados sin el permiso del usuario. |
| Backdoor | Puerta trasera donde pueden acceder a sistemas sin métodos de autentificación. |
| Bomba Fork | Malware que crea procesos hasta consumir todos los recursos del sistema. |
| Caballo de Troya | Malware que parece bueno, pero oculta sus funciones maliciosas para no aparentar maldad. | 
| Cookies | Restos que dejas de que has visitado la pagina. |
| Crackers | Usuarios que rompen las protecciones de programas o sistemas. |
| Cryptovirus, Ransomware | Cifra archivos a cambio de una remuneración. |
| Exploits | Vulnerabilidad que se puede llegar a explotar. |
| Hijaker | Malware modifica configuración del navegador, como el inicio o el buscador. |
| Hoax, Joke, Bulo | Mensaje falso que puede asustar, engañar o confundir al usuario. |
| Keystroke o Keylogger | Malware que registra las teclas pulsadas para obtener información. |
| Ladilla virtual | Programa que hace que tu dispositivo se para o realentice. |
| Leapfrog | Desde un dispositivo que ha atacado accede a los otros sistemas o redes. |
| Parásito informático | Malware que se junta a archivos o los modifica para hacer actos malos. |
| Pharming | Tecnica que redirige al usuario a otra pagina web. |
| Phising | Técnica utilizada para mediante correos o mensajes para conseguir contraseñas. |
| Rabbit o conejos | Malware que se reproduce muchas veces, consumiendo memoria y procesos. |
| Riskware | Software legítimo pero que supone un riesgo si no se utiliza bien. |
| Rootkit | Conjunto de herramientas que entre ellas se esconde un programa maliciosos. |
| Scumware | Software no deseado que muestra la publicidad. |
| Spam | Ataque masivo de correos basura. |
| Spyware | Malware espía que recopila información del usuario. |
| Pop-Ups o Ventanas emergentes | Ventanas que aparecen automáticas sin consentimiento. |
| Worms o gusanos | Malware que se replica y se extiende entre redes. |
